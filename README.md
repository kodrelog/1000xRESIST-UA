# 1000xRESIST — українізатор

Неофіційний фанатський переклад гри [1000xRESIST](https://store.steampowered.com/app/1675830/) українською.

![Українізатор 1000xRESIST](logo.png)

## Що перекладено

- Усі діалоги й варіанти відповідей (~13 700 унікальних реплік)
- Меню, налаштування, підказки керування
- Вступна оповідь, катсцени, кінцівки
- Імена й терміни світу гри — за єдиним глосарієм

Озвучення лишається англійським — перекладено субтитри й увесь текст.

**Поточна версія:** редакція 4 (27.10.2026) · Steam-версія гри для Windows

## Встановлення

1. Закрийте гру.
2. Завантажте `1000xRESIST_UA_v4.zip` з розділу [Releases](../../releases/latest) і розпакуйте.
3. Запустіть `1000xRESIST_UA.exe` і оберіть пункт **1 — встановити**. Встановлювач сам знайде гру в бібліотеці Steam; якщо не знайде — покладіть EXE у папку гри й запустіть звідти.
4. У грі: **Settings → System → Text Language → French**.

**Чому French?** Гра не дає додати нову мову, тому переклад стає на місце французької. Після вибору пункт меню називатиметься «Українська».

Встановлювач не містить файлів гри — лише текст перекладу. Він збирає змінені файли з ваших оригіналів і перед цим робить резервну копію в папку `_UA_backup` у папці гри.

## Видалення

Запустіть `1000xRESIST_UA.exe` → пункт **2 — відкат**.
Або: Steam → ПКМ по грі → Властивості → Встановлені файли → **Перевірити цілісність файлів гри**.

## Якщо гра оновилася

Оновлення гри перезаписує файли перекладу. Встановлювач перевіряє файли: якщо вони не збігаються з очікуваними, він нічого не змінює й попередить. Перевірте цілісність файлів у Steam і завантажте свіжу версію перекладу.

## Відомі проблеми

- **Антивірус або SmartScreen може попередити про EXE.** Це типово для програм, зібраних через PyInstaller. Хеш SHA-256 кожного файлу — в описі релізу.
- Окремі рядки можуть лишитися англійською: частина реплік у грі не має місця під переклад.
- Знайшли помилку чи неперекладений текст? Відкрийте [Issue](../../issues): розділ гри, що на екрані, бажано зі скриншотом.
